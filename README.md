# Video Anomaly Detection in CCTV

Dissertation project investigating semi-supervised deep learning for CCTV anomaly detection, using reconstruction-based video models.

## Key finding
Identified a temporal evaluation bias in standard benchmarks that inflates reported accuracy — confirmed through statistical and ablation-based analysis.

## Built with
Python, PyTorch, SLURM/HPC

## Note
Trained on shared HPC cluster resources; large datasets and checkpoints are not included in this repo.
